# content/

角色卡、世界书、prompt 模板。许可：**CC-BY-SA-4.0**。

这里放的是**可复用的角色**，而不是某个世界的一部分。世界包（`worlds/`）引用这里的卡，
或者自带自己的卡。

## 角色卡应包含

- 人格：身份、说话方式、三个特征、想要什么、怕什么。
- 知识边界：他**不知道**什么（比知道什么更重要）。
- 行为约束：什么情况下会撒谎、会动手、会退让。
- 分级建议：这个角色适合 T0 / T1 / T2。
