# 灰港（官方示例世界）

一个用来说明规范、也用来做引擎垂直切片测试的小世界：三个区域、两个势力、三个 NPC、五条知识。

- **许可**：CC-BY-SA-4.0（见 `manifest.json`）
- **分级**：默认 T0——不接任何模型也能完整玩
- **规模**：3 区域 / 11 实体 / 5 知识

## 改这个世界的规矩

1. 改完跑 `python tools/validate/validate.py worlds/official`。
2. 知识条目必须独立可读——它们会被单独塞进 NPC 的上下文。
3. 新增 NPC 时，先想清楚他**不知道**什么。一个什么都知道的 NPC 会让世界失去重量。
4. 引用现实中的地名、人名、作品前，确认没有版权问题。
