# engine/

游戏引擎。许可：**MIT**。

状态：尚未开始。这里先记下它必须满足的约束，写代码时别绕。

## 约束

1. **无 LLM 也是完整游戏。** 所有 NPC 在 T0 下必须能工作，包括战斗、交易、给线索。
2. **确定性。** 同一存档 + 同一随机种子 = 同一结果。所有随机走统一 RNG，禁止 `Random()` 散落各处。
3. **规则权威。** 模型只能提交「动作意图」，合法性由引擎判定；不合法就拒绝并返回原因。
4. **只读世界包。** 引擎不写 `worlds/`，玩家状态写存档目录。
5. **不链接 AGPL。** 需要 lorekeeper 时通过 localhost HTTP 或子进程调用。

## 垂直切片（第一个里程碑）

- 8×8 方格地图，一张手写世界包（就用 `worlds/official`）。
- 六部位、每个部位 1–2 个技能、3 AP、1 反应点。
- 两个 NPC：一个 T0（模板台词）、一个 T2（可选接模型）。
- 一场可胜可败可求饶的战斗。
- 一次对话，能因为「知道/不知道某条知识」而产生不同结果。

做到这五条，架构就验证完了。
