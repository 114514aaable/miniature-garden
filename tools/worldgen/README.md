# tools/worldgen/

世界生成器。许可：**AGPL-3.0-or-later**。独立 CLI，不链接引擎。

输入：一段种子描述（题材、规模、基调）+ 随机种子。
输出：一个能过 `tools/validate` 的世界包目录。

## 流水线

```
提案（LLM） → 结构化校验 → 批评（LLM/规则） → 修复 → 世界包
```

关键点：

- **LLM 只产提案，不产最终文件。** 所有输出必须先转成符合 schema 的结构，再由确定性代码
  补齐缺口（缺 id、缺引用、缺区域）。
- **可复现**：`seed + prompt_version + model` 三者相同 → 世界包相同（或至少可 diff）。
- **产出的包必须过校验器**，否则生成器算失败。
