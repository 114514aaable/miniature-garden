# `game/systems/i18n/i18n.ts`

## 内容

i18n：界面文字走 key，不写死在代码里。
三条规矩：
1. 找不到 key 时**显示 key 本身**，不显示空白——空白最难查；
2. 参数用 `{name}` 占位，保持简单，不做 ICU 复数规则（需要时再加）；
3. 语言包是普通对象，可以用 JSON 存，也可以让 mod 覆盖。
