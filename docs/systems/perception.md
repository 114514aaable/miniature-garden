# 体系：信息组（感知 / 掩码）

> 改这里如果：**你要做视野、迷雾、声音、潜行、致盲，或者「日志不该剧透」**。

## 它解决什么

世界有两套「事实」：

```
绝对事实   谁在哪、多少血、在蓄力        ← 服务端模拟用，唯一真相
感知事实   某个观察者知道什么            ← 界面、日志、AI 用
```

**不分开，做视野就是白做**——日志和 AI 会把没看见的事全说出来。

## 双翻译器

```
绝对事件链（append-only）
   │
   ├─ 绝对翻译器  → AbsoluteFacts    全知
   └─ 感知翻译器  → PerceivedFacts   按 mask 过滤、降精度
```

- **绝对翻译器**已经有：`game/systems/intel/facts.ts`
- **感知翻译器**要新增：`game/systems/intel/perceive.ts`

## 归属

| 东西 | 在哪 | 形态 |
|---|---|---|
| `core.mask` 组件 | base 包 | 数据 |
| 感知引擎（射线、缓冲、翻译） | `game/systems/intel/` | 代码 |
| 玩家日志 | `game/systems/log/` | **只消费感知事实** |

**掩码跟观察者绑定，不是全局开关**：

```json
"core.mask": {
  "vision": { "radius": -1, "shape": "circle", "blockedBy": "solid" },
  "hearing": { "radius": -1 },
  "memory": { "decay": 0 }
}
```

`-1` = 无限 = **玩家默认全知**。以后开「有限信息模块」只改这个组件。

## 感知的三种精度

| 事件 | 有视野 | 只有听觉 | 都没有 |
|---|---|---|---|
| 敌人在动 | 具体位置 | 「西边有动静」 | 什么都不知道 |
| 敌人起手 | 看到预警格 | 「蓄力声」 | 不知道 |
| 宝箱打开 | 看到 | 听到 | 不知道 |

**「不完全信息」不是全有全无，是精度不同。**

## 不变量

1. **存档存绝对事实**——否则读档后「记忆」会乱；
2. **界面与日志只消费感知事实**；
3. **AI 也吃感知视图**，否则等于开透视；
4. 默认 `radius: -1`，行为与现在完全一致。

## 扩展路径

```
1. Mask 结构 + 全知观察者        ← 零行为变化
2. 视野半径 + 遮挡（Bresenham）   ← 撞到 solid 就断
3. 声音事件（范围 + 衰减）        ← 事件带 perceivable 标签
4. AI 走感知视图                 ← 接口切换
```
